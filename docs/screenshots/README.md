# Screenshots

Add screenshots here and they will appear in the main [README](../../README.md).

Suggested files:

- `landing.png` — the public landing page
- `dashboard.png` — the dashboard with stats
- `patients.png` — the patients table
- `dark-mode.png` — any screen in dark mode

**How to capture:** run `npm run dev`, sign in, and take screenshots at a 16:10 viewport
(e.g. 1280×800) for a consistent look.
